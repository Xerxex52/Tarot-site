Questions fréquentes

Comment jouer en ligne ?
Accueil → Jouer → Jouer en ligne. Choisissez un nom et un avatar. Un joueur crée la table et partage le code à 4 chiffres ; les autres le saisissent. Deux comptes Game Center différents sont nécessaires.

Faut-il un compte Simorgh ?
Non. Le hors ligne ne demande aucun compte. Le multijoueur utilise Game Center (Apple).

Y a-t-il des publicités ?
Non. L’app est payante, sans publicité et sans achat intégré.

Comment changer mon nom ?
Dans Réglages (roue dentée) ou dans le lobby Jouer en ligne, avant de créer ou rejoindre une table.
