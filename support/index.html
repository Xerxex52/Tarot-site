Aide pour Tarot : Salon des Arcanes sur iPhone et iPad.

Questions fréquentes

Je vois une publicité après une partie.
C’est normal en version gratuite : une pub peut s’afficher à la fin d’une donne. Achetez « Mode Pro — Sans publicité » dans Réglages pour les supprimer définitivement.

Comment restaurer un achat ?
Ouvrez Réglages dans l’app, puis utilisez « Restaurer les achats » avec le même compte Apple.

L’app fonctionne-t-elle hors ligne ?
Oui pour jouer. Une connexion Internet est nécessaire uniquement pour les publicités (version gratuite) et les achats intégrés.

Règles du Tarot.
Consultez la section Règles dans l’application pour le détail des enchères, du chien et des plis.

Nous contacter

Pour un bug, une question App Store ou une demande liée à la confidentialité, écrivez-nous depuis l’adresse e-mail associée à votre compte Apple ID utilisé pour le test ou l’achat, en indiquant le modèle d’appareil et la version iOS :

support@simorgh.app
